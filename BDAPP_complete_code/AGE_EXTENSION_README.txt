BDAPP AGE EXTENSION — 27 October 2026

This add-on is in age_extension, alongside the original FinalSpark/DANDI/Zenodo project.

Target: days post dissociation in organoid-derived 2D cultures, from published five-minute recordings.
Not intact-organoid biological age, a one-hour recording model, or remaining lifespan.

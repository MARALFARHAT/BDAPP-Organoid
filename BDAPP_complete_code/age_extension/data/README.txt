METHODOLOGICAL INFORMATION\
\
Description of methods used for collection of data: Continuous MEA recordings of dissociated organoids were made across all electrodes in real time using the Axion Maestro and Axis Navigator software (12.5 kHz sampling rate, 200-3000 Hz band-pass) and were saved as .raw files. .raw files were processed using Axion Axis Navigator and Neural Metrics Tool, as well as the Matlab MEA network analysis pipeline (please see the associated publication methods for details.)\
\
Methods for processing the data: CSV files containing only the well summary data were imported into R and collated. The data is rearranged so that each column corresponds to one variable or metadata category. Please see the associated publication for details.\
\
Instrument- or software-specific information needed to interpret the data: .raw files can be opened using Axion Axis Navigator or Matlab. .raw files can be converted to .mat files using MEA-NAP: https://github.com/SAND-Lab/MEA-NAP or similar. \
\
Environmental/experimental conditions:\
Daily recordings across four cell lines and multiple batches were conducted up to 29 DPD. In the metadata and CSV files, KOLF2.1J is abbreviated to KOLF and SCTi003-A is abbreviated to SCT. From 29 DPD onwards, E2 or vehicle treatment was applied following a baseline recording, followed by a \'93treated\'94 recording for 15 minutes, 5 minutes after treatment after equilibrating in the MEA Maestro. Note that for plates 5-8, estrogen receptor agonists WAY-200070 [10nM] and PPT [100 nM] were added in place of E2. While this data is not discussed in the associated publication, we have included it in the metadata for completeness to allow for analysis of RAW data files.\
\
Missing data codes: NA indicates the parameter was not measurable in the well. Wells without any treatment have NA in the condition column.\
\
Metadata definitions:\
\
recording_filename_well - the .raw file name with the well letter and number appended following the underscore. Note that AP# indicated the plate number, as some plates contained cells from two cell lines. The first number following plate number indicates the day at which whole organoids were dissociated. The second number indicates the additional days post dissociation.\
\
treatment_timepoint - length of time that has elapsed at the time of recording since the treatment, specified in Condition.\
\
condition - treatment applied to the well. NA indicates no treatment.\
\
cell_line - the cell line from which the cells in the well indicated were derived from.\
\
batch - organoids generated from a different passage number of cells on a different day are considered different batches.\
\
age_DPD - days post dissociation, or culture time of dissociated cells on the MEA. Organoids were typically grown for 45-46 days prior to dissociation. DPD is in addition to this culture time.\
\
CSV files contain all parameters exported from MEA-NAP and Axion Neural Metrics tool. For any abbreviations not defined in the associated publication, please see the Axion Neural Metrics Definitions Document published by Axion, and the MEA-NAP README: https://github.com/SAND-Lab/MEA-NAP}

This ZIP contains summaries and figures, not original NWB recordings.

IMPLEMENTED OUTPUTS
Per recording: event counts, active hardware-channel counts, events divided by
nominal recording duration, channel interval mean/CV, fixed-ISI burst features,
mean absolute native amplitude, unresolved mapping counts, metadata and audits.
Per culture: session counts and recording date coverage.
Figures: descriptive activity and burst participation over recording elapsed time.
Unsupported/invalid files are skipped with an explicit reason in the audit.

SCIENTIFIC SCOPE
These files describe dissociated rat cortical cultures, not human organoids.
Subject age P18D with gestational reference is donor age at dissection, not
culture age during recording. Culture age remains blank.
Days since first successfully processed session is only a recording chronology.
Source channels are not identified single neurons. The exact source event table
is processing/ecephys/detected_spikes, rather than a standard NWB Units table.
Relative times begin at the first detected spike. The initial recording silence
cannot be reconstructed. No absolute event times are guessed.
Overall event rate uses the converter-reported recording duration, not a verified
continuous-exposure measurement. Amplitude retains source-native units.
A channel burst requires at least five detections joined by intervals <=100 ms.
No neuron-specific burst claims, biological-age prediction, survival model,
causal claims or pooled FinalSpark model validation occur in this code stage.

REAL-FILE VERIFICATION

Downloaded sample SHA-256 values matched DANDI asset metadata.
